# Viably Automation Service

GitHub automation service powered by NVIDIA Nemotron for intelligent code generation.

## Quick Start

```bash
# Install dependencies
npm install

# Configure environment
cp .env.example .env
# Add your NVIDIA_API_KEY and GITHUB_TOKEN

# Start server
npm start
```

Server runs on `http://localhost:3002`

## API Endpoints

**POST /api/implementation-flow**
- Orchestrates 4-step implementation workflow
- Input: Viably analysis, target repo, search context
- Output: PR details, team assignments, training needs

## Architecture

- **NVIDIA Nemotron**: Code generation and planning
- **GitHub API**: Automated PR creation
- **Team Matching**: Engineer skill-based assignment
- **Ripgrep Integration**: Codebase search
