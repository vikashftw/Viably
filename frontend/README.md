# Viably Frontend

**Next.js dashboard for product analysis results**

## Setup
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Key Components
- `app/components/AnalysisResults.tsx` - 6-section accordion dashboard
- `app/components/ImplementationFlow.tsx` - 4-step progress tracker
- `app/page.tsx` - Main input form

## Configuration
Set in `.env.local`:
```
VIABLY_BACKEND_URL=http://localhost:8000
```
